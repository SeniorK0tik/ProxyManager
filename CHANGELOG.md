## [0.1.0] - 2026-10-02

Первый выпуск.

### Добавлено

- Перехват исходящего трафика выбранных приложений через драйвер WinDivert и перенаправление на локальный relay. Определение процесса-владельца по таблицам TCP/UDP.
- Upstream-прокси SOCKS5 и HTTP CONNECT, оба с авторизацией по логину и паролю.
- Несколько прокси-профилей. Действие для каждого правила: через прокси, напрямую или блокировать. Отдельное действие для приложений без правила.
- Правила по имени файла, полному пути или маске (`*`, `?`), без учёта регистра. Изменения применяются на лету.
- Блокировка UDP у проксируемых приложений, чтобы трафик (в том числе QUIC) не уходил мимо прокси. DNS (порт 53) пропускается.
- Если прокси недоступен, соединение приложения сбрасывается, а не уходит напрямую.
- Список исключений (LAN, loopback, multicast по умолчанию): такие адреса никогда не проксируются.
- Графический интерфейс на egui с вкладками «Правила», «Прокси» (с проверкой прокси), «Процессы», «Соединения», «Журнал» и «Настройки».
- Иконка в трее, сворачивание в трей, автозапуск при входе в Windows через Планировщик заданий.
- Запрос прав администратора (UAC) при старте и автоматическое правило брандмауэра Windows для relay.
- Аргументы командной строки `--config`, `--start`, `--minimized`, `--no-elevate`.
- Конфигурация в `%APPDATA%\ProxyManager\config.toml`, логи в `%APPDATA%\ProxyManager\logs`.
- Тесты: unit, интеграционные, headless-тесты GUI и end-to-end на реальном драйвере WinDivert.
- CI на GitHub Actions: проверки, тесты с порогом покрытия 90%, сборка для Windows. Публикация релиза по тегу `v*` с описанием из этого файла.
